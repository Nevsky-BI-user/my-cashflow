# Монета ₴: ассети анімації «Розподіл зарплати 21-го»

## Призначення

У день виплати на Огляді є картка з кроками розподілу: Ощад · житло, Приват · погашення,
Монобанк · погашення, Готівка 3 000, Заощадження, Монобанк · решта. Виконавець анімації:
золота монета ₴.

- На картці зарплати монета повільно обертається (`coin-spin`).
- Тап на крок: монета перелітає по дузі з картки зарплати в картку рахунку за 0,6 с
  і перекидається в польоті (`coin-flip`); сума на картці докручується синхронно.
- Коли всі кроки зроблено, монета зникає стриманим золотим спалахом: короткий теплий
  відблиск, кільце світла і кілька золотих іскор (`coin-burst`), без інших кольорів.
- Статичний аверс 3/4 (`coin-still`) для режиму без руху і місць без анімації.

Монета зібрана процедурно в Blender (Cycles, GPU OptiX): товстий диск із фаскою,
бортиком, намистовим обідком і рифленим гуртом (120 рифлів); на аверсі рельєфний ₴
(шрифт Arial Bold із системи), на реверсі стрілка росту з лого. Матеріал: поліроване
золото поля (дрібна рівномірна зношеність, без плям) і насичено-золотий сатиновий
рельєф знаку з плоскою фаскою, мікроподряпини, патина в западинах. Світло студійне:
софтбокси, діагональна смуга для блику, тепле відбите світло знизу (монета лишається
золотою в перекиданні) і тонкі бірюзова, індиго та фіолетова смуги, що дають
бренд-відблиск на фасці й гурті. Тло прозоре, motion blur вимкнено. Нічого не завантажується з інтернету.

## Файли

`assets/coin/` (WebP з альфою, стиснення з втратами, method 6, loop 0; quality 80 для
spin, flip і still, 85 для burst; спрайти: PNG із палітрою 256 кольорів і альфою):

| Файл | Кадри | Розмір | Кадр | Тривалість | Вага |
|---|---|---|---|---|---|
| `coin-spin.webp` | 24 | 160x160 | 42 мс | 1,0 с, петля без шва | 129 КБ |
| `coin-flip.webp` | 12 | 160x160 | 50 мс | 0,6 с, один оберт за цикл | 62 КБ |
| `coin-burst.webp` | 14 | 200x200 | 50 мс | 0,7 с | 140 КБ |
| `coin-still.webp` | 1 | 256x256 | | | 12 КБ |
| `coin-spin-sprite.png` | 24 в ряд | 3840x160 | | запасний варіант | 94 КБ |
| `coin-flip-sprite.png` | 12 в ряд | 1920x160 | | запасний варіант | 47 КБ |
| `coin-burst-sprite.png` | 14 в ряд | 2800x200 | | для одноразового спалаху | 90 КБ |

Ліміти брифу: spin до 350 КБ, flip до 200 КБ, burst до 300 КБ, still до 60 КБ.
Ширина монети в кадрі 1 (за альфою, скрипт): spin 0,875 кадру, flip 0,800 (монета
розвернута на 28 градусів), burst 0,690 (решта місця для іскор). При показі spin у 56 px
монета має 49 px, тож спалах показувати у 72 px (розрахунок 71 px): тоді монета не
стрибає в розмірі на стику перельоту і спалаху.

`mascot/`:

- `coin.py`: сцена Blender (модель, матеріали, світло, рендер кадрів);
- `pack_coin.py`: зменшення кадрів (у премультиплікованому просторі, без темної облямівки),
  сяйво спалаху, WebP і PNG-спрайти;
- `verify_coin.py`: перевірка розмірів, альфи, ваги, кількості кадрів і шва петлі;
- `coin-demo.html`: демо перельоту у світлій і темній темах;
- `shoot_demo.py`: знімки демо в headless Chromium без звуку, результат у `mascot/shots/`.

## Перегенерація однією командою

PowerShell з кореня репозиторію (рендер близько 45 с на RTX 5070; перший запуск ще
хвилину-дві компілює ядра OptiX):

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b -noaudio --factory-startup -P mascot\coin.py; if ($?) { python mascot\pack_coin.py }; if ($?) { python mascot\verify_coin.py }
```

- Blender лише так: `-b -noaudio --factory-startup`, звук на ПК заборонено.
- Кадри пишуться в `%TEMP%\coin-frames`, старі кадри кожного режиму видаляються перед рендером.
- Частковий рендер: після `-P mascot\coin.py` додати `-- --only spin` (або `still,flip,burst`);
  інші ключі: `--samples 256`, `--light-scale 0.6`, `--view AgX`.
- `pack_coin.py` і `verify_coin.py` потребують Pillow і numpy у системному Python
  (у `.venv` їх немає; `.venv` потрібен лише для Playwright у `shoot_demo.py`).
- Знімки демо: `.venv\Scripts\python.exe mascot\shoot_demo.py`.

## Як вбудувати в index.html

Шляхи від кореня застосунку: `assets/coin/...`. Нові файли додати в `ASSETS` у `sw.js`
і підняти `CACHE`.

### CSS

```css
:root { --coin: 56px; --burst: 72px; }

/* монета на картці зарплати: петля обертання */
.coin-idle { width: var(--coin); height: var(--coin); }

/* монета в польоті: позиціонується transform-ом у шарі над картками */
.coin-fly {
  position: absolute; left: 0; top: 0; width: var(--coin); height: var(--coin);
  pointer-events: none; will-change: transform; z-index: 3;
  filter: drop-shadow(0 10px 8px rgba(0, 0, 0, .28));
}

/* спалах: спрайт і steps(14), грає рівно один раз */
.coin-burst {
  position: absolute; left: 0; top: 0; width: var(--burst); height: var(--burst);
  pointer-events: none; z-index: 4;
  background: url("assets/coin/coin-burst-sprite.png") 0 0 / calc(var(--burst) * 14) 100% no-repeat;
  animation: coin-burst 700ms steps(14) forwards;
}
@keyframes coin-burst { to { background-position-x: calc(var(--burst) * -14); } }

@media (prefers-reduced-motion: reduce) {
  .coin-fly, .coin-burst { display: none; }
}
```

### Розмітка і переліт

- На картці зарплати: `<img class="coin-idle" src="assets/coin/coin-spin.webp" width="160" height="160" alt="">`.
- Точка приземлення: праворуч від суми на картці рахунку, на висоті суми, з резервом
  у половину `--burst` від правого краю картки, щоб ні монета, ні іскри спалаху не
  закрили число. Якщо праворуч від суми місця нема, монета сідає в правий верхній кут.
  Елемент суми має бути завширшки з текст (`align-self: flex-start` у колонковому flex),
  інакше його прямокутник тягнеться на всю картку. Готова функція `landing()` є в
  `mascot/coin-demo.html`; `shoot_demo.py` перевіряє, що перетину з сумою нема.
- Переліт: створити `<img class="coin-fly" src="assets/coin/coin-flip.webp">` у спільному
  батьківському контейнері карток (`position: relative`), сховати `.coin-idle`
  і анімувати Web Animations API: 600 мс, `easing: 'ease-out'`, `fill: 'forwards'`.
  Ключові кадри: 16-17 точок квадратичної кривої Безьє від монети до точки приземлення,
  контрольна точка над серединою на `0,35 * відстань + 30` px, масштаб
  `1 + 0,18 * sin(pi * t)` (монета ближче до глядача на вершині дуги).
  Готова функція `arcFrames()` є в `mascot/coin-demo.html`.
- Сума докручується з `anim.effect.getComputedTiming().progress`: це вже прогрес після
  ease-out, тому число й монета йдуть синхронно і зупиняються разом.
- Після `anim.finished`: прибрати `.coin-fly`, записати кінцеву суму, позначити крок
  зробленим. Якщо кроки ще лишились, повернути `.coin-idle` на картку зарплати.
- Після останнього кроку: поставити `.coin-burst` центром на місце монети, прибрати
  на `animationend`, `.coin-idle` більше не показувати.

### Тривалості

| Подія | Тривалість |
|---|---|
| Петля обертання на картці | 1,0 с (24 x 42 мс), безкінечно |
| Переліт | 600 мс, ease-out; цикл `coin-flip` теж 600 мс (12 x 50 мс) |
| Спалах | 700 мс (14 x 50 мс), один раз |

### Без руху (prefers-reduced-motion)

- На картці зарплати замість `coin-spin.webp` показати `coin-still.webp`.
- Тап на крок: одразу кінцеві суми і позначка «зроблено», без `.coin-fly` і `.coin-burst`.
- Перевіряти через `matchMedia('(prefers-reduced-motion: reduce)')` у JS і продублювати
  `@media` у CSS.

### Застереження

- Усі WebP мають `loop=0`, тобто грають безкінечно. Для `coin-spin` це потрібно, для
  `coin-flip` нешкідливо (елемент живе 600 мс). `coin-burst.webp` у `<img>` теж
  зациклиться і не перезапуститься з початку при повторному показі того самого URL,
  тому для одноразового спалаху використовувати спрайт `coin-burst-sprite.png` зі
  `steps(14)`, як у CSS вище. Варіант із WebP: показати `<img>` і прибрати через 700 мс.
- Фаза `coin-flip.webp` не синхронізована з перельотом: браузер веде анімацію однакового
  URL спільним таймлайном, тож монета стартує з довільного кадру оберту. Для перекидання
  саме з аверсу на старті брати `coin-flip-sprite.png` зі `steps(12)` за 600 мс
  (аналогічно до спалаху).
- PNG-спрайти зберігаються з палітрою 256 кольорів і дизерингом: різниця з повноколірним
  варіантом на око не помітна, а вага в 4-6 разів менша. У кеш SW додавати лише те, що
  реально використовується.
