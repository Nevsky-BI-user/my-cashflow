# spec: перевірки в браузері

Перевірки `index.html` у Chromium через Python Playwright. Без pytest і без npm: корінь проєкту лишається без збірки.

## Запуск

```
python spec/run.py
```

Опції:

- `--headed`: показувати вікно браузера;
- `--only <назва>`: лише перевірки, у назві яких є цей текст, або всі перевірки модуля (`--only board`);
- `--keep`: після прогону лишити превʼю-сервер (адресу друкує раннер), Ctrl+C зупиняє.

Код виходу 1, якщо хоч одна перевірка впала. Прогін триває близько двох хвилин: застосунок показує заставку 2,4 с на кожній свіжій сторінці.

Потрібно: Python 3 і пакет `playwright` із завантаженим Chromium (`python -m playwright install chromium`, якщо браузера ще немає). Мережа потрібна для CDN (React); відповіді CDN раннер кешує в памʼяті на час прогону.

## Як це працює

- `preview.py` збирає копію `index.html` у `spec/.out/preview/`: прибирає тег supabase-js (застосунок іде на демо-даних), вимикає реєстрацію service worker, прибирає `sb&&` біля кнопок, які без БД сховані. Якщо шаблон рецепта зник з `index.html`, збірка падає з назвою шаблону. Потім піднімає `http.server` на вільному порту в окремому потоці.
- `run.py` для кожної перевірки відкриває свіжий контекст браузера (чистий localStorage, у ньому лише `tour_done`, щоб тур не заважав; перевірка самого туру йде без нього), чекає на інтерфейс і викликає функцію перевірки. `console.error` і `pageerror` вважаються провалом.
- Скриншоти перевірок лягають у `spec/.out/shots/`. Тека `spec/.out/` у git не потрапляє.

## Як додати перевірку

1. Новий файл `spec/checks/<тема>.py` (файли з `_` на початку раннер пропускає).
2. Функція отримує `page` (Playwright, сторінка вже завантажена) і падає з `AssertionError` при порушенні; зручно через `check(умова, 'що не так')` з `helpers.py`.
3. Наприкінці модуля список:

```python
CHECKS = [
    ('Назва українською', 'desktop', fn),   # desktop: 1280x860, mobile: 375x812
    ('Тур без tour_done', 'desktop', fn2, {'tour': True}),  # необовʼязкові опції
]
```

Помічники в `helpers.py`: `go_tab(page, i)`, `dialog(page, 'Назва')`, `shot(page, 'файл.jpg')`, `TABS`.
